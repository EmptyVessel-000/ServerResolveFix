# ServerResolveFix

修复 Minecraft 原版多人服务器地址解析：原版只读取第一条 DNS SRV 记录并从不回退到下一条（MC-86722 / MC-49826）。

模组读取全部 SRV 记录，按 RFC 2782 排序（优先级从低到高，同优先级加权），并在列表刷新时选出第一个能连通的地址；加入服务器时直接复用这次选择，而不是重新探测。

## 行为

- 无 SRV、单条 SRV、或非默认端口时，返回与原版完全相同的结果，不做任何额外操作。
- 多条 SRV 时按顺序探测，选第一个能连通的；全部不可达时退回最高优先级那条，让报错与原版一致。
- SRV 目标解析失败时退回域名本身的 A 记录，原版不会这样做。
- 选择结果按主机名和端口缓存，服务器列表下次刷新时更新。
- 无配置、无界面、无命令、不写文件。

## 构建

需要 JDK 21（1.20.4 版本线由 toolchain 自动下载 JDK 17），网络需可达 `maven.neoforged.net`。

```
gradlew.bat build --project-prop=mc=1.20.4
gradlew.bat build --project-prop=mc=1.20.6
gradlew.bat build
```

| `-Pmc` | Minecraft | NeoForge | Java |
|---|---|---|---|
| `1.20.4` | 1.20.2 – 1.20.4 | 20.4.253+ | 17 |
| `1.20.6` | 1.20.5 – 1.20.6 | 20.6.144+ | 21 |
| 默认 `1.21.1` | 1.21 – 1.21.8 | 21.1.265+ | 21 |

产物在 `build/libs/serverresolvefix-<mc>-1.0.0.jar`。Forge 1.19.x 与 1.20.1 不在覆盖范围内。

## 安装

把 jar 放进客户端 `mods` 目录，客户端侧使用。
